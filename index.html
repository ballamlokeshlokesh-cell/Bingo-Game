❓ How to Play Multiplayer Bingo

1

Create or Join with Team Code

One player chooses the square matrix (25 numbers or 100 numbers) and generates a team code. Friends enter the code to join.

2

Unique Random Matrix for Everyone

When the match starts, each player receives a uniquely shuffled arrangement of numbers on their board.

3

Random Turn Order & Automatic Cross-Out

The system randomly determines player turn order. When a player calls a number on their turn, that number automatically cancels / strikes out on all players' boards in real time!

4

Complete 5 Lines for B-I-N-G-O

Complete horizontal, vertical, or diagonal lines. In 5x5, each line lights up a letter in B-I-N-G-O. First player to achieve all required lines wins!
