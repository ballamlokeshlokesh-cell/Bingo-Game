# Bingo Game

A small, responsive Bingo game that runs directly in your browser. It uses plain HTML, CSS, and JavaScript, so there are no packages, build steps, or external script dependencies to install.

## Play

1. Open `index.html` in a modern web browser, or enable GitHub Pages for this repository and visit the published site.
2. Select **Call next number** to draw a random Bingo number. Called numbers are marked on the board automatically.
3. Get five marked squares in a horizontal, vertical, or diagonal line to win.
4. Select **New game** to shuffle the board and start over.

The center square is a free space. This version is a single-player browser game and does not require a server or database.

## GitHub Pages

In the repository, open **Settings → Pages**, choose the `main` branch and `/ (root)` as the publishing source, and save. Once the deployment completes, open the Pages URL shown in that section.
